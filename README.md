# CloseAI para o Claude

A análise das suas reuniões comerciais, dentro do seu Claude. O CloseAI lê a transcrição, mostra o
que já se sabe do negócio e o que falta saber, e prepara o que escrever no seu CRM — que só é escrito
com o seu sim.

## Instalar na app do Claude

1. **Plugin:** em **Customize › Plugins › Add › Add marketplace**, escreva
   `Agens-Consulting/closeai-plugin` e instale o plugin **closeai**.
2. **Ligar a conta:** quando o Claude pedir, entre com a sua conta Google em `app.closeai.pt`.
3. **Primeiro uso:** peça ao Claude «instala o CloseAI» (ou `/closeai:instalar`) e siga os passos.

Conta grátis e mais informação em [app.closeai.pt](https://app.closeai.pt).

## O que está aqui

Só as instruções do plugin (skills e subagentes) e o endereço do servidor CloseAI. A análise corre
com as instruções servidas pelo CloseAI; nada neste repositório guarda dados seus.

Feito pela [Agens](https://agens.pt).
